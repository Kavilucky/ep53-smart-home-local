# Умный дом без облаков: комплект к ролику

Комплект к выпуску L03 канала «ByteAutomate» — https://t.me/ByteAutomate_AI. Ведущий: Константин.

Локальный умный дом: Home Assistant OS, брокер Mosquitto и Zigbee2MQTT. Команды, датчики и логика остаются внутри квартиры, облако производителя не участвует. Секретов в комплекте нет.

> **Честная пометка.** Всё ниже собрано по официальной документации (ссылки в конце). Физический стенд для ролика не подключался: примеры конфигов и автоматизаций проверьте на своём железе и тестовых устройствах, прежде чем опираться на них. Имена сущностей (`light.hallway` и т. п.) в примерах условные, подставьте свои.

## Шаг 1. Установите Home Assistant OS

1. Выберите сервер (см. `HARDWARE_CHECKLIST.md`): Raspberry Pi 4 или 5 (минимум 2 ГБ памяти, лучше с SSD вместо карты) либо обычный 64-разрядный ПК, который умеет грузиться в режиме UEFI.
2. Скачайте образ Home Assistant OS со страницы установки (https://www.home-assistant.io/installation/) и запишите его на носитель по инструкции для вашей платформы. Для обычного ПК нужна флешка от 8 ГБ.
3. Подключите сервер кабелем к роутеру, включите, подождите несколько минут.
4. Откройте в браузере `http://homeassistant.local:8123` (если имя не находится, используйте IP-адрес сервера из роутера). Создайте **локальную** учётную запись: облачный аккаунт не нужен.

## Шаг 2. Закрепите за сервером постоянный адрес

В настройках роутера зарезервируйте IP-адрес за сервером (привязка к MAC-адресу). Названия пунктов зависят от роутера.

## Шаг 3. Установите брокер Mosquitto

1. В Home Assistant: **Настройки → Приложения** (в версиях до 2026.2 раздел назывался «Дополнения») → магазин → **Mosquitto broker** → установить и запустить.
2. Home Assistant предложит подключить интеграцию **MQTT**: подтвердите. Официальное приложение настраивается автоматически, пароль генерируется само.

## Шаг 4. Установите Zigbee2MQTT

Приложения доступны только в Home Assistant OS; для Zigbee2MQTT поддерживаются 64-разрядные платформы.

1. **Настройки → Приложения → магазин → ⋮ → Репозитории**, добавьте репозиторий `https://github.com/zigbee2mqtt/hassio-zigbee2mqtt`, установите приложение Zigbee2MQTT.
2. Подключите стик через USB-удлинитель (см. чек-лист). Путь к стику можно найти в **Настройки → Система → Оборудование → ⋮ → Системное оборудование** (ищите `/dev/serial/by-id/…`).
3. Запустите приложение и откройте его веб-интерфейс (**Show in sidebar** — показать в боковом меню). При первом запуске откроется мастер настройки: выберите ваш адаптер из списка найденных; если его нет, введите путь вручную.
4. Тип адаптера: **ZBDongle-E → `ember`**, **ZBDongle-P → `zstack`** (примеры в папке `zigbee2mqtt/`). Параметр `adapter: ezsp` устарел.
5. Выберите Zigbee-канал с учётом вашей сети Wi-Fi 2,4 ГГц. Документация советует каналы 11, 15, 20 или 25.
6. Адрес брокера для приложения: `mqtt://core-mosquitto:1883`.

> Настройки, заданные на странице конфигурации приложения, имеют приоритет над `configuration.yaml` (так сказано в документации приложения). Если хотите управлять всем через YAML, уберите их оттуда.

Чтобы устройства автоматически появились в Home Assistant, в конфигурации Zigbee2MQTT должно быть `homeassistant: enabled: true`, а интеграция MQTT включена (шаг 3).

## Шаг 5. Подключите датчик

1. В интерфейсе Zigbee2MQTT нажмите **Permit join (All)**: сеть открывается на 254 секунды (кнопка в правом верхнем углу).
2. На датчике зажмите кнопку сброса, пока не замигает светодиод. Точная процедура указана на странице вашей модели в каталоге Supported devices: https://www.zigbee2mqtt.io/supported-devices/
3. Через несколько секунд устройство появится в списке и в Home Assistant. Начинайте с устройств с питанием от розетки: они образуют ячеистую сеть и ретранслируют сигнал, батарейные датчики добавляйте потом.

## Шаг 6. Резервные копии и удалённый доступ

- Настройте резервные копии по расписанию и храните их не только на самом сервере: см. `BACKUP-3-2-1.md`.
- Для доступа извне используйте собственный VPN (например WireGuard или Tailscale). Не пробрасывайте порт Home Assistant в интернет напрямую.

## Три сценария

Файлы в папке `automations/` добавляются через **Настройки → Автоматизации → ⋮ → Редактировать в YAML** либо в `automations.yaml`. Перед включением замените сущности на свои и протестируйте. Для третьего сценария сначала добавьте `homeassistant/helpers.example.yaml`.

1. `01_night_hallway_light.yaml` — свет по движению ночью.
2. `02_leak_protection.yaml` — защита от протечки.
3. `03_leaving_home.yaml` — «ухожу из дома» с охраной по датчику двери.

Интернет нужен только для уведомления на телефон, если вас нет дома; всё остальное идёт внутри квартиры.
