# Чек-лист совместимого железа

Основан на официальной документации Home Assistant и Zigbee2MQTT. Конкретные модели датчиков здесь намеренно не рекомендуются: совместимость проверяйте по каталогу https://www.zigbee2mqtt.io/supported-devices/ перед покупкой.

## 1. Сервер

Вариант А: Raspberry Pi
- [ ] Raspberry Pi 4 или 5 с блоком питания
- [ ] минимум 2 ГБ оперативной памяти (по странице установки Home Assistant)
- [ ] SSD вместо карты памяти (при постоянной записи карты изнашиваются)
- [ ] кабель Ethernet к роутеру

Вариант Б: обычный мини-ПК или ПК (Generic x86-64)
- [ ] процессор Intel или AMD, 64-разрядная система
- [ ] загрузка в режиме UEFI (на большинстве систем последних десяти лет она есть)
- [ ] загрузочный носитель поддерживает 512-байтные логические секторы (большинство накопителей; часть NVMe и жёстких дисков с 4K-секторами не подходит)
- [ ] флешка от 8 ГБ для установки
- [ ] выделенный компьютер: система Home Assistant OS записывается на накопитель целиком
- [ ] кабель Ethernet к роутеру

Для Zigbee2MQTT как приложения нужна 64-разрядная платформа (aarch64 или amd64).

## 2. Zigbee-координатор

- [ ] SONOFF ZBDongle-P (чип Texas Instruments): `adapter: zstack`
- [ ] SONOFF ZBDongle-E (чип Silicon Labs): `adapter: ember` (прошивка 7.4 и новее; `ezsp` устарел)
- [ ] USB-удлинитель, лучше экранированный, от 50 см
- [ ] стик подключён в порт USB 2, а не USB 3, подальше от SSD, роутера и других радиоустройств
- [ ] ориентация стика и расстояние до порта HDMI проверены: близкий порт может сильно глушить сигнал

## 3. Устройства

- [ ] версия Zigbee, а не Wi-Fi (многие датчики Aqara, Xiaomi и Tuya бывают в обеих версиях: проверьте маркировку)
- [ ] модель найдена в каталоге Supported devices Zigbee2MQTT и прочитана инструкция по сопряжению на странице модели
- [ ] хотя бы несколько устройств с питанием от розетки (розетки, реле): они образуют ячеистую сеть и ретранслируют сигнал
- [ ] датчик движения, датчик открытия двери, датчик протечки воды, умная розетка: набор под три сценария из ролика
- [ ] для охраны по сценарию 3: сирена или любое устройство оповещения, которое можно включать из Home Assistant
- [ ] камеры и часть техники работают по Wi-Fi: выбирайте модели с поддержкой локального управления

## 4. Сеть и питание

- [ ] за сервером закреплён постоянный IP-адрес в роутере
- [ ] сервер подключён к бесперебойному питанию или хотя бы к удлинителю с защитой (по желанию)
- [ ] резервные копии настроены, носитель для копий не только на самом сервере (см. `BACKUP-3-2-1.md`)

## 5. Перед первым запуском

- [ ] нашли путь к стику: Настройки → Система → Оборудование → Системное оборудование (`/dev/serial/by-id/…`)
- [ ] выбрали Zigbee-канал с учётом вашей сети Wi-Fi 2,4 ГГц (рекомендуются каналы 11, 15, 20, 25)
- [ ] не пробрасываете порт Home Assistant в интернет; для доступа извне есть собственный VPN
